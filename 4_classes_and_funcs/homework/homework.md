## Домашнее задание 4 — Продвинутый Python: синтаксический сахар, типизация, парадигмы программирования

1. Перепишите предоставленный "плохой" процедурный скрипт в идиоматичный Python: используйте подходящий синтаксический сахар (распаковку, walrus, comprehensions), добавьте type hints ко всем функциям и обработку исключений для некорректных строк входных данных.
2. Опишите с помощью `@dataclass` структуру "Транзакция" (id, дата, сумма, категория) и реализуйте для неё класс-агрегатор `TransactionAggregator` с методами `add()` и `total_by_category()`. Затем реализуйте ту же агрегацию в чисто функциональном стиле (без классов) и сравните в комментарии плюсы/минусы.
3. Реализуйте декоратор `@retry(n)`, который повторяет вызов функции до `n` раз при возникновении исключения, и контекстный менеджер, который замеряет время выполнения блока кода.
4. Реализуйте конвейер обработки данных как цепочку генераторов: `read_lines(path)` → `parse_records(lines)` → `filter_valid(records)` → `transform(records)`, где каждый шаг — отдельный генератор, и данные обрабатываются по одной записи без загрузки всего файла в память. Объясните в комментарии, почему это особенно полезно для очень больших файлов.
5. Реализуйте класс `BatchIterator`, который принимает список (или другой итерируемый объект) и размер батча, и реализует протокол итератора (`__iter__`/`__next__`), отдавая данные пакетами заданного размера (последний пакет может быть меньше). Покажите использование в цикле `for`.

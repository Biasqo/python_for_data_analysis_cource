# Класс в Python

## Определение
Класс - модель для создания объектов определённого типа, описывающая их структуру.

## Что происходит при написании `class`
1. Python создает новое пространство имен (словарь).
2. Выполняет код внутри класса сверху вниз - все `def` становятся методами, присваивания - атрибутами класса.
3. Создает объект класса типа `type` (или метакласса) и связывает его с именем.
4. При вызове `MyClass()`:
   - `__new__` создает пустой экземпляр.
   - `__init__` инициализирует его состояние.

## Парадигма
Классы - фундаментальная конструкция **объектно-ориентированного программирования (ООП)**. Python реализует ООП через:

- **Инкапсуляцию** - данные и методы внутри класса скрывают внутреннее устройство.
- **Наследование** - создание иерархий, переиспользование кода через расширение родительских классов.
- **Полиморфизм** - единый интерфейс для разных реализаций (один метод, разное поведение).
- **Абстракцию** - выделение общего контракта через абстрактные базовые классы (ABC).

## Правила чистого кода
- Класс должен делать что-то одно и делать это хорошо.
- Имя - существительное в единственном числе с заглавной буквы (`Order`, `Payment`).
- Избегайте общих имен (`Manager`, `Handler`, `Data`).
- Держите классы небольшими - 50–100 строк, не более.
- Методы должны быть короткими и делать что-то одно в рамках проектной области.
- Внедряйте зависимости через конструктор (`__init__`), а не создавайте внутри.
- Предпочитайте композицию наследованию - собирайте поведение из маленьких классов.
- Используйте абстракции (протоколы, ABC) для гибкости и тестируемости.
- Класс - это граница: внутри - детали реализации, снаружи - публичный интерфейс.

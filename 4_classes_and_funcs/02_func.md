# Функции в Python

## Определение
Функция - блок организованного, многократно используемого кода, который выполняет одно конкретное действие. Функция принимает входные данные (аргументы), обрабатывает их и возвращает результат.

## Что происходит при написании `def`
1. Python создает объект функции в памяти.
2. Код внутри функции не выполняется - он сохраняется как байт-код в атрибуте `__code__`.
3. Создается объект типа `function` и связывается с именем.
4. При вызове `my_func()`:
   - Создается локальное пространство имен (стек вызова).
   - Аргументы связываются с параметрами.
   - Выполняется байт-код функции.
   - При `return` значение возвращается, локальное пространство удаляется.
   - Если `return` нет, возвращается `None`.

## Парадигма
Функции - фундаментальная конструкция **процедурного программирования**. Python реализует процедурный подход через:

- **Модульность** - разбиение задачи на небольшие, переиспользуемые функции.
- **Абстракцию** - сокрытие деталей реализации за именем функции.
- **Композицию** - построение сложных операций из простых функций.
- **Чистоту** (опционально) - функции без побочных эффектов и с предсказуемым результатом (pure functions).

## Правила чистого кода
- Функция должна делать что-то одно и делать это хорошо.
- Имя - глагол в настоящем времени (`calculate_total`, `get_user`).
- Избегайте общих имен (`process`, `handle`, `run`, `do`).
- Держите функции небольшими - 5-10 строк, не более 20.
- Количество аргументов: 0-2 идеально, 3 допустимо, 4+ - повод для рефакторинга.
- Внедряйте зависимости через аргументы, а не через глобальные переменные.
- Предпочитайте явные возвращаемые значения изменению глобального состояния.
- Используйте аннотации типов для документации и проверки (`def get_user(id: int) -> User:`).
- Документируйте сложные функции через docstring.
- Избегайте побочных эффектов - функция должна только возвращать результат.
- Проверяйте входные данные в начале функции (fail fast).
- Обрабатывайте ошибки на уровне, где есть контекст для их обработки.
- Функция - это единица переиспользования: она должна быть самодостаточной.

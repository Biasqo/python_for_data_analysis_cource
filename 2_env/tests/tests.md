## Проверка понимания

1. Коллега прислал вам `environment.yml`. Какая одна команда воссоздаёт его окружение?
   > `conda env create -f environment.yml`

2. Почему `.env` должен быть в `.gitignore`?
   > Он содержит секреты (API-ключи, пароли). История git постоянна: однажды запушив, вы компрометируете секреты навсегда.

3. Что не так с этим `requirements.txt`?
   ```
   pandas
   numpy
   ```
   > Нет фиксации версий. Другой разработчик (или вы в будущем) получит последнюю версию, которая может вести себя иначе. Используйте `pandas==2.1.0` и т.д.

4. Когда стоит выбрать conda вместо venv?
   > Когда нужно управлять самой версией Python, когда пакеты требуют скомпилированных нативных расширений (например, MKL NumPy), или на Windows, где сборка C-расширений через pip вызывает сложности.

# Домашнее задание 2

## Задание 1. Создание и проверка venv-окружения

1. Создайте новую папку для проекта `homework_2_project` и перейдите в неё.
2. Создайте виртуальное окружение с помощью стандартного модуля `venv` (используйте рекомендованное имя директории).
3. Активируйте окружение.
4. Проверьте, что вы находитесь внутри окружения **двумя разными способами**:
   - через переменную окружения;
   - через команду `which`/`where`.
5. Откройте файл `pyvenv.cfg` внутри созданной директории окружения и выпишите в отчёт три параметра, которые в нём указаны, и что каждый из них означает.

## Задание 2. Установка пакетов и фиксация версий

Работайте в окружении из Задания 1.

1. Установите внутри окружения пакеты `pandas`, `numpy` и `requests`, зафиксировав **конкретные версии** при установке.
2. Сохраните список установленных пакетов в файл `requirements.txt`.
3. Создайте второй файл `requirements-dev.txt`, который:
   - подключает основной `requirements.txt`;
   - дополнительно содержит `pytest` и `black` с указанием диапазона версий (не точной версии).
4. Удалите окружение и создайте его заново «с нуля».
5. Установите все зависимости в новое окружение одной командой, используя файл `requirements.txt`.
6. Объясните своими словами в чём разница между подходом «точная фиксация версии» и «диапазон версий», и в каких случаях какой подход уместен.

## Задание 3. Jupyter и регистрация ядра

1. В venv из Задания 1 установите `ipykernel`.
2. Зарегистрируйте это окружение как отдельное ядро Jupyter с понятным отображаемым именем (`--display-name`).
3. Выведите список всех зарегистрированных ядер на вашей машине.
4. Запустите Jupyter Lab и создайте ноутбук `notebooks/02_homework.ipynb`, в котором:
   - выберите только что зарегистрированное ядро;
   - в первой ячейке используйте магическую команду для замера времени выполнения ячейки;
   - во второй ячейке выведите список всех переменных текущей сессии с помощью магической команды;
   - подключите `%load_ext autoreload` с режимом полной автоперезагрузки модулей.
5. Удалите зарегистрированное ядро командой из урока и снова выведите список ядер, чтобы убедиться, что оно пропало.

## Задание 4. Организация проекта по шаблону урока

Соберите для `homework_2_project` структуру каталогов и файлов

1. Создайте директории: `data/raw`, `data/processed`, `data/external`, `notebooks`, `src/homework_2_project`, `tests`.
2. Внутри `src/homework_2_project` создайте файлы `__init__.py`, `data.py`, `features.py`, `models.py`, `utils.py` (содержимое может быть минимальным важна структура).
3. Создайте файл `.env` с двумя любыми переменными (например, `API_KEY`, `USER`).
4. Напишите короткий `README.md` для проекта с разделом «Настройка», чтобы ваш коллега смог настроить себе проект аналогичным способом

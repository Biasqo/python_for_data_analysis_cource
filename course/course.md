# Программирование на Python

## Тема 1. Python: синтаксис и экосистема
Основные типы данных. Приведение типов. Операторы.

## Тема 2. Виртуальное окружение
Виртуальные окружения virtualenv и conda. Изоляция зависимостей проекта. Управление пакетами и версиями Python в отдельных окружениях.

## Тема 3. Структуры данных Python
Базовые структуры данных языка Python и их особенности использования.

## Тема 4. Продвинутый Python
Синтаксический сахар. Типизация в Python. Основные парадигмы программирования: объектно-ориентированное, процедурное, функциональное.

## Тема 5. AsyncIO и Multiprocessing
Асинхронное программирование с использованием AsyncIO. Параллельные вычисления средствами Multiprocessing. Ограничения, связанные с GIL, и способы их обхода.

## Тема 6. Библиотеки для работы с данными
NumPy: Работа с массивами NumPy. Векторизованные вычисления. Pandas: Структуры данных Series и DataFrame. Чтение и запись данных в различных форматах. Группировка и агрегация данных. Объединение таблиц. Работа с временными рядами. Разведочный анализ данных (EDA). Polars: Особенности библиотеки Polars. Сравнение с pandas по производительности и функциональности. Pyspark: Основы распределённой обработки данных с PySpark.

## Тема 7. Визуализация: matplotlib и seaborn
Построение графиков средствами matplotlib и seaborn. Основные приёмы визуализации данных. Разработка интерактивных дэшбордов на Streamlit.

## Тема 8. ETL и оркестрация
Процессы Extract-Transform-Load. Инструменты оркестрации задач обработки данных.

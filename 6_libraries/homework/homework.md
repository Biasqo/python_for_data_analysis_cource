## Домашнее задание 6 — NumPy: массивы и векторизация

1. Дан 2D-массив `prices` формы `(n_дней, n_акций)`. Векторизованным кодом (без явных циклов) вычислите дневную процентную доходность каждой акции и определите акцию с наибольшей средней доходностью.
2. Дан 2D-массив показаний датчиков формы `(1000, 5)`. Векторизованным кодом: замените отрицательные значения на `NaN`, посчитайте среднее по столбцам, игнорируя `NaN`, и помечайте строки, где какое-либо значение отклоняется от среднего своего столбца более чем на 3 стандартных отклонения.
3. Короткий письменный ответ: объясните разницу между view и copy в NumPy и почему это важно при изменении срезов массива. Приведите пример кода, в котором эта разница приводит к неожиданному результату.
4. Дан массив точек на плоскости формы `(n, 2)`. Векторизованным кодом (без циклов, используя broadcasting) вычислите матрицу попарных евклидовых расстояний `(n, n)` между всеми точками. Сравните по времени с реализацией через вложенные циклы для `n=1000`.
5. Создайте два больших массива (`~10 млн элементов`) — один в порядке `C` (row-major), другой в порядке `F` (column-major) — и сравните время суммирования по строкам и по столбцам для каждого из них. Объясните результат через понятие memory layout и cache locality.

# Глава 8. Pandas II: группировка, объединение, время, EDA

## GroupBy и сводные таблицы

- **groupby** - группировка по одному или нескольким столбцам + агрегация (sum, mean, count, std). `.unstack()` - превратить в широкую таблицу.
- **Именованные агрегации** - `agg(имя=("столбец","функция"))`, можно с кастомной функцией (lambda).
- **transform** - агрегат той же формы, что исходная таблица (не схлопывает строки): доля от суммы группы, z-score внутри группы.
- **pivot_table** - сводная таблица как в Excel (values/index/columns/aggfunc/margins).
- **melt** - обратная операция: широкая таблица → длинная.

```
agg vs transform
  результат схлопывает строки?  → agg
  результат той же формы?       → transform
```

## Объединение данных

- **concat** - склеивание таблиц: по строкам (одинаковые столбцы) или по столбцам.
- **merge** - аналог SQL JOIN: inner / left, разные имена ключей (left_on/right_on), `validate` - проверка типа связи, проверка пропусков после left join.
- **join** - упрощённый merge по индексу.

```
concat vs merge vs join
  просто сложить одинаковые таблицы   → concat
  объединение по ключевому столбцу    → merge
  объединение по общему индексу       → join
```

## Пропуски и время

- **Пропуски**: обнаружение (isna), удаление (dropna: все/subset/thresh), заполнение (медиана/константа/ffill/bfill), интерполяция для рядов.
- **category dtype** - экономия памяти при малом числе уникальных значений.
- **Дата и время**: `to_datetime`, аксессор `.dt` (год/месяц/день недели/квартал), арифметика с датами, resample (агрегация по периодам), rolling (скользящее среднее).

```
Как обработать пропуски
  мало и не критично     → dropna
  числовой столбец       → fillna(медиана/среднее)
  категориальный столбец → fillna(константа)
  временной ряд          → ffill / bfill / interpolate
```

## EDA

- **describe()** - статистика по числовым и категориальным столбцам.
- **value_counts** - частоты категорий; **pd.cut** - разбивка числовой переменной на диапазоны.
- **Корреляции** - матрица + тепловая карта (seaborn).
- **Выбросы**: метод IQR (1.5×IQR от квартилей) или Z-score (|z|>3), проверка через гистограмму/boxplot.

```
Как искать выбросы
  распределение скошено      → метод IQR
  распределение близко к нормальному → метод Z-score
```

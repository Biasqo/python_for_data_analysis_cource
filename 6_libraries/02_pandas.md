### Что такое pandas?

`Pandas` - основная библиотека Python для работы с табличными данными.

Под капотом NumPy - это даёт скорость и интеграцию с энтерпрайзом.

Две главные структуры:
1) Series - одномерный массив с метками (индексом). Своего рода столбец в таблице.
2) DataFrame - двумерная таблица: строки + столбцы с метками.

Индексация:
- В Series и DataFrame у каждой строки есть индекс (метка).
- Индекс может быть числовым, строковым, датой и т.д.
- Доступ по метке работает через .loc[] (по имени) и .iloc[] (по позиции).

Выравнивание:
- При арифметике (сложение, вычитание и т.д.) данные выравниваются по индексу автоматически.
- Это ключевая фишка pandas: не нужно заботиться о порядке строк.

Основные возможности:
- Загрузка и сохранение данных (CSV, Excel, SQL, JSON, Parquet).
- Просмотр и описание данных (головы, хвосты, типы, статистика).
- Выборка строк и столбцов (по имени, по позиции, по условию).
- Фильтрация с помощью булевых масок.
- Добавление, удаление, переименование столбцов.
- Сортировка по одному или нескольким столбцам.
- Группировка и агрегация (groupby, pivot_table).
- Объединение таблиц (concat, merge - как JOIN в SQL).
- Работа с пропусками (удалить, заполнить).
- Работа с датами и временными рядами.
- Применение функций к элементам, столбцам, строкам.
- Иерархические индексы (MultiIndex).

Особенности:
- Индексы автоматически выравниваются при операциях.
- Пропуски (NaN) не ломают вычисления.
- Поддерживаются большие объёмы данных (но не безгранично).
- Многие операции возвращают копию, а не изменяют исходные данные.

### Series vs DataFrame

| | Series | DataFrame |
|---|---|---|
| Размерность | 1D (массив с метками) | 2D (строки + столбцы) |
| Аналог | столбец таблицы | таблица целиком |
| Создание | `pd.Series([...], index=[...])` | `pd.DataFrame({"col": [...]})` |
| Доступ по метке | `s["DE"]` | `df.loc["DE"]` |
| Доступ по позиции | `s.iloc[0]` | `df.iloc[0]` |
| Арифметика | выравнивание по индексу | выравнивание по индексу и столбцам |

### loc vs iloc

| | `.loc` | `.iloc` |
|---|---|---|
| Работает по | меткам (именам) | позициям (числам) |
| Правая граница среза | включена | НЕ включена |
| `df.loc["DE":"IT"]` | включает "IT" | - |
| `df.iloc[0:2]` | - | строки 0 и 1, без 2 |
| Ошибка | `.loc[0]` при строковом индексе → `KeyError` | `.iloc["DE"]` → `TypeError` |

### Чтение (`read_*`) → Запись (`to_*`)

| Формат | Чтение | Запись | Особенность |
|---|---|---|---|
| CSV | `pd.read_csv()` | `df.to_csv()` | универсально, но медленно, нет типов |
| Excel | `pd.read_excel()` | `df.to_excel()` | `sheet_name` |
| JSON | `pd.read_json()` | `df.to_json()` | поддерживает вложенность |
| Parquet | `pd.read_parquet()` | `df.to_parquet()` | быстро, компактно, хранит типы ✓ |
| SQL | `pd.read_sql()` | `df.to_sql()` | нужно подключение к БД |
| Pickle | `pd.read_pickle()` | `df.to_pickle()` | только доверенные источники |
| HTML | `pd.read_html()` | - | возвращает список DataFrame |

**Схема потока I/O:**

```
Источник данных (CSV / JSON / SQL / Parquet)
            │
            ▼  read_*()
       pandas DataFrame  ──►  df.dtypes  (обязательно проверить!)
            │
            ▼  обработка: фильтрация → apply/map → astype
       DataFrame (чистый)
            │
            ▼  to_*()
Результат (CSV / Excel / Parquet / JSON)
```

### Фильтрация - от простого к читаемому

| Способ | Код | Комментарий |
|---|---|---|
| Булева маска | `df[df["сумма"] > 500]` | базовый вариант |
| Несколько условий | `df[(df.a>1) & (df.b=="x")]` | скобки обязательны |
| Список значений | `df[df["cat"].isin([...])]` | вхождение |
| Инверсия | `df[~df["cat"].isin([...])]` | всё, кроме списка |
| Пропуски | `df[df["x"].notna()]` | без NaN |
| Читаемый синтаксис | `df.query("сумма > 100 and cat=='еда'")` | эквивалент маски |

**Цепочка принятия решения:**

```
Нужно отобрать строки?
   │
   ├─ простое условие ──► df[df["col"] > x]
   │
   ├─ несколько условий ──► df[(cond1) & (cond2)]
   │
   ├─ список значений ──► df["col"].isin([...])
   │
   └─ читаемость важнее ──► df.query("...")
```

### Работа со столбцами

| Метод | Что делает | Скорость |
|---|---|---|
| `.apply(func)` | функция к каждому элементу/строке | медленно (цикл Python) |
| `.map(dict/func)` | точечная замена значений | быстро |
| `.str.lower/strip/replace` | строковые операции | векторизовано, быстро |
| `.astype(type)` | приведение типа | быстро |
| `.rename(columns={...})` | переименование | мгновенно |

#### 1. Обработка заказов

В очереди лежат 6 заказов. Их обрабатывают 3 обработчика одновременно.

```python
import asyncio
import time


async def process(order_id: int) -> str:
    await asyncio.sleep(0.5)
    return f"order {order_id} done"
```

**Задание**
* Напишите `async def worker(name, queue)`: пока очередь не пуста, берёт заказ из очереди, вызывает `process` и печатает `name: результат`.
* В `main()` создайте `asyncio.Queue`, положите в неё номера заказов 1-6, запустите 3 обработчика конкурентно (`w1`, `w2`, `w3`) и выведите общее время работы.
* Ответьте: сколько заняла бы обработка одним обработчиком?

**Примеры** (порядок строк может отличаться)
```text
w1: order 1 done
w2: order 2 done
w3: order 3 done
w1: order 4 done
w2: order 5 done
w3: order 6 done
time 1.0
```

**Подсказка**
Заказы в очередь кладите через `queue.put_nowait(i)`. Проверка, что очередь не пуста: `while not queue.empty():`. Конкурентный запуск обработчиков: `asyncio.gather`.

#### 2. pandas и Polars

Дана выгрузка продаж двух магазинов за 5 дней. Значение `qty < 0` - это возврат, а `qty = 0` - пустая строка.

```python
import pandas as pd
import polars as pl

data = {
    "day":     ["2024-05-01", "2024-05-01", "2024-05-02", "2024-05-02", "2024-05-03",
                "2024-05-03", "2024-05-04", "2024-05-04", "2024-05-05", "2024-05-05"],
    "shop":    ["Центр", "Юг", "Центр", "Юг", "Центр", "Юг", "Центр", "Юг", "Центр", "Юг"],
    "product": ["чай", "кофе", "кофе", "чай", "чай", "кофе", "кофе", "чай", "чай", "кофе"],
    "qty":     [10, 5, 8, 12, -2, 7, 6, 0, 9, 4],
    "price":   [150.0, 300.0, 300.0, 150.0, 150.0, 300.0, 300.0, 150.0, 150.0, 300.0],
}

df_pd = pd.DataFrame(data)
df_pl = pl.DataFrame(data)
```

**Задание**
Выполните шаги сначала на **pandas**, затем на **Polars**. В Polars используйте Lazy API (`.lazy()` → ... → `.collect()`).
1. Преобразуйте `day` из строки в дату и добавьте столбец `revenue = qty * price`.
2. Оставьте только строки с `qty > 0`.
3. Для каждого магазина посчитайте общую выручку `total`, среднее количество `avg_qty` и число продаж `orders`.
4. Для каждого магазина найдите товар с наибольшей суммарной выручкой.

Затем заполните таблицу (одна короткая фраза в ячейке):

| | pandas | Polars |
|---|---|---|
| Как добавляют новый столбец | | |
| Как фильтруют строки по условию | | |
| Меняется ли исходная таблица | | |
| Когда выполняется запрос | | |

**Примеры**
```text
Шаг 3:
shop   total   avg_qty  orders
```

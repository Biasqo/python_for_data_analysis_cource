#### 1. Обработка заказов

В очереди лежат 6 заказов. Их обрабатывают 3 обработчика одновременно.

```python
import asyncio
import time


async def process(order_id: int) -> str:
    await asyncio.sleep(0.5)
    return f"order {order_id} done"
```

**Задание**
* Напишите функцию `worker(name, queue)`: пока очередь не пуста, берёт заказ из очереди, вызывает `process` и печатает `name: результат`.
* Создайте функцию `main()`, поместите туда `asyncio.Queue`, положите в неё номера заказов 1-6, запустите 3 обработчика конкурентно (`w1`, `w2`, `w3`) и выведите общее время работы.
* Сколько заняла бы обработка одним обработчиком?

**Примеры** (порядок строк может отличаться)
```text
w1: order 1 done
w2: order 2 done
w3: order 3 done
w1: order 4 done
w2: order 5 done
w3: order 6 done
time 1.0
```

**Подсказка**
Заказы в очередь кладите через `queue.put_nowait(i)`. Проверка, что очередь не пуста: `while not queue.empty():`. Конкурентный запуск обработчиков: `asyncio.gather`.
Документация: https://docs.python.org/3/library/asyncio-queue.html

#### 2. Простые операции с pandas и Polars

Дана выгрузка продаж за 2024 год в файле `sales.csv`. 
Столбцы: `дата`, `регион`, `категория`, `клиент`, `сумма`.

```python
import pandas as pd
import polars as pl

df_pd = pd.read_csv("sales.csv")
df_pl = pl.read_csv("sales.csv")
```

**Задание**
Пошагово выполните:
1. Преобразуйте `event_dt` из строки в дату и добавьте столбец `event_mnth` - номер месяца.
2. Оставьте только покупки с `amount > 500`.
3. Для каждого региона посчитайте общую выручку `total`, средний чек `avg_check` и количество покупок `orders`.
4. Для каждого региона найдите категорию с наибольшей суммарной выручкой (`total`).
В Polars используйте Lazy API (`pl.scan_csv(...)` или `.lazy()` → ... → `.collect()`).

### 0–20 | Series и DataFrame

#### Что такое pandas?

pandas — это главная библиотека Python для табличных данных. Она построена поверх NumPy и предоставляет две ключевые структуры данных: **Series** (одномерная) и **DataFrame** (двумерная таблица).

#### Series

```python
import pandas as pd
import numpy as np

# Создание из списка
s = pd.Series([10, 20, 30, 40])
print(s)
# 0    10
# 1    20
# 2    30
# 3    40
# dtype: int64

# Создание с пользовательским индексом
gdp = pd.Series(
    [4.07, 2.78, 2.10, 1.77],
    index=["DE", "FR", "IT", "ES"],
    name="ВВП (трлн USD)"
)
print(gdp["DE"])    # 4.07
print(gdp[["DE", "IT"]])  # выборка нескольких элементов

# Арифметика с Series — выравнивание по индексу
inflation = pd.Series({"DE": 2.1, "FR": 2.5, "IT": 3.0, "ES": 3.5})
real_gdp = gdp - (gdp * inflation / 100)
print(real_gdp)
```

#### DataFrame — создание

```python
# Из словаря списков

    "страна":    ["Германия", "Франция", "Италия", "Испания"],

    "инфляция":  [2.1, 2.5, 3.0, 3.5],
    "население": [83.2, 67.8, 59.6, 47.4],

df4 = pd.DataFrame(df[["страна", "ввп"]])
```

### 45–70 | Индексация и фильтрация

#### `loc` vs `iloc`

```python
df = pd.DataFrame({
    "страна":  ["Германия", "Франция", "Италия", "Испания"],
    "ввп":     [4.07, 2.78, 2.10, 1.77],
    "рейтинг": [1, 2, 3, 4],
}, index=["DE", "FR", "IT", "ES"])

# loc — по меткам (включает правую границу!)
print(df.loc["DE"])               # строка с меткой "DE"
print(df.loc["DE", "ввп"])        # конкретная ячейка
print(df.loc["DE":"IT", "ввп"])   # срез по меткам (включая "IT")
print(df.loc[["DE", "ES"]])       # несколько строк

# iloc — по позициям (НЕ включает правую границу, как Python)
print(df.iloc[0])                 # первая строка
print(df.iloc[0, 1])              # строка 0, столбец 1
print(df.iloc[0:2])               # строки 0 и 1 (не включая 2)
print(df.iloc[:, 0:2])            # все строки, столбцы 0 и 1

# Типичная ошибка: перепутать loc и iloc
# df.loc[0]   — ищет метку 0 (ошибка, если индекс ["DE", "FR", ...])
# df.iloc["DE"]  — ошибка, iloc принимает только числа
```

#### Булевы маски

```python
df = pd.read_csv("transactions.csv")

# Простой фильтр
mask = df["сумма"] > 500
df_дорогие = df[mask]

# Несколько условий — обязательно скобки!
df_выборка = df[(df["сумма"] > 100) & (df["категория"] == "еда")]
df_или = df[(df["категория"] == "еда") | (df["категория"] == "транспорт")]

# isin — для проверки вхождения в список
категории = ["еда", "транспорт", "здоровье"]
df_нужные = df[df["категория"].isin(категории)]

# ~  — инверсия маски
df_остальные = df[~df["категория"].isin(категории)]

# notna / isna
df_без_пропусков = df[df["сумма"].notna()]
```

#### `.query()` — читаемый синтаксис

```python
# Эквивалент булевой маски, но читается проще
df_выборка = df.query("сумма > 100 and категория == 'еда'")

# С переменными из окружения (используйте @)
порог = 500
df_дорогие = df.query("сумма > @порог")
```

#### `.copy()` и SettingWithCopyWarning

```python
# ПРОБЛЕМА: изменение среза может не изменить исходный DataFrame
df_еда = df[df["категория"] == "еда"]
df_еда["наценка"] = df_еда["сумма"] * 0.1  # ⚠️ SettingWithCopyWarning!

# РЕШЕНИЕ: явно создать копию
df_еда = df[df["категория"] == "еда"].copy()
df_еда["наценка"] = df_еда["сумма"] * 0.1  # ✓ теперь безопасно
```

### 70–90 | Работа со столбцами

#### `.apply()` — применение функции к столбцу

```python
# К одному столбцу (Series)
df["сумма_с_ндс"] = df["сумма"].apply(lambda x: x * 1.2)

# Пользовательская функция
def классифицировать(сумма):
    if сумма < 100:
        return "малая"
    elif сумма < 1000:
        return "средняя"
    return "крупная"

df["размер"] = df["сумма"].apply(классифицировать)

# К нескольким столбцам (axis=1 — применять к каждой строке)
df["описание"] = df.apply(
    lambda row: f"{row['категория']}: {row['сумма']:.2f} руб.",
    axis=1
)

# ⚠️ .apply() — это цикл Python! Медленно на больших данных.
# Предпочитайте векторизованные операции NumPy/pandas.
```

#### `.map()` — замена значений

```python
# Замена через словарь
кат_код = {"еда": 1, "транспорт": 2, "электроника": 3}
```

#### Строковые методы `.str`

```python
# Все методы доступны через аксессор .str
df["категория"] = df["категория"].str.lower()           # в нижний регистр
df["категория"] = df["категория"].str.strip()           # убрать пробелы
df["категория"] = df["категория"].str.replace("-", "_") # замена

# Проверки
df["есть_скидка"] = df["описание"].str.contains("скидка", na=False)

# Разбивка
df[["имя", "фамилия"]] = df["полное_имя"].str.split(" ", expand=True)

# Извлечение по регулярному выражению

```

## Живая демонстрация: загрузка и очистка транзакционного датасета

```python
import pandas as pd

# Имитация "грязного" датасета
data = {
    "ID":        ["T001", "T002", "T003", "T004", "T005"],
    "Сумма":     ["250,00", "1 200.50", "N/A", "89.5", "3000"],
    "Категория": ["  Еда ", "ЭЛЕКТРОНИКА", "еда", "Транспорт", "электроника"],
    "Дата":      ["2024-01-15", "15/01/2024", "2024-01-16", "2024-01-17", "Jan 18, 2024"],
    "Клиент":    ["Иван Иванов", "Мария Петрова", None, "Сергей Сидоров", "Анна Козлова"],
}
df = pd.DataFrame(data)

print("=== Исходные данные ===")
print(df)
print(df.dtypes)

# Шаг 1: очистка столбца "Сумма"
df["Сумма"] = (df["Сумма"]
    .str.replace(",", ".")     # запятые → точки
    .str.replace(" ", "")      # убрать пробелы
    .replace("N/A", pd.NA)     # явный пропуск
    .astype(float)             # приведение к числу
)

# Шаг 2: нормализация категорий
df["Категория"] = df["Категория"].str.strip().str.lower()

# Шаг 3: разбор дат (несколько форматов — используем dayfirst и format inference)
df["Дата"] = pd.to_datetime(df["Дата"], dayfirst=False, infer_datetime_format=True)

# Шаг 4: разбивка имени клиента
df[["Имя", "Фамилия"]] = df["Клиент"].str.split(" ", expand=True)

print("\n=== После очистки ===")
print(df)
print(df.dtypes)
```

## Проверка понимания

**5 вопросов:**

1. В чём разница между `df.loc[0]` и `df.iloc[0]`?
   > `loc` использует метку индекса (строку с меткой `0`), `iloc` — позицию (первую строку). Если индекс не числовой, `loc[0]` вызовет ошибку, а `iloc[0]` всегда вернёт первую строку.

2. Почему не стоит изменять срез DataFrame напрямую?
   > Срез может быть либо представлением, либо копией — pandas не гарантирует. Изменение среза может не изменить оригинал и вызывает `SettingWithCopyWarning`. Решение: всегда вызывать `.copy()`.

3. Когда предпочесть Parquet вместо CSV?
   > При больших данных, регулярно читаемых кодом (а не людьми): Parquet сохраняет типы, читается в разы быстрее и занимает значительно меньше места.

4. Чем `.map()` отличается от `.apply()`?
   > `.map()` работает поэлементно с одной Series и принимает словарь или функцию. `.apply()` гибче: может работать со всем столбцом или построчно по DataFrame (`axis=1`).

5. Как прочитать CSV-файл размером 10 ГБ при 8 ГБ оперативной памяти?
   > Использовать `pd.read_csv(..., chunksize=N)` для пообработочного чтения и обработки, или загрузить только нужные столбцы через `usecols=[...]`, или переключиться на Parquet/Polars/PySpark.

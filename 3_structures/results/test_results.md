## Задание 2. Найдите ошибку

```
TypeError: unhashable type: 'list'
```

Ошибка возникает потому, что `list` - изменяемый тип и не может использоваться как ключ словаря (ключи должны быть хешируемыми, а хешируемыми могут быть только неизменяемые объекты).

## Задание 3. `is` или `==`?

Правильно использовать **`is None`**. `None` - единственный экземпляр своего типа (`NoneType`) в памяти интерпретатора, поэтому сравнение через `is` проверяет идентичность объекта, что быстрее и семантически корректнее. Использование `==` теоретически может дать неожиданный результат, если у сравниваемого объекта переопределён метод `__eq__` так, что он возвращает `True` при сравнении с `None`.

## Задание 4. Предскажите вывод

```python
print(x)          # (1, 2, 3)
print(y)          # (1, 2, 3, 4)
print(x is y)     # False
```

Объяснение: `tuple` неизменяем, поэтому `y = y + (4,)` не изменяет исходный кортеж, а создаёт **новый** объект и присваивает его переменной `y`. Исходный `x` остаётся нетронутым, и после этой операции `x` и `y` указывают на разные объекты в памяти.

## Задание 6. Поверхностная копия

**Да**, `a["items"]` изменится - результат: `a["items"] == [1, 2, 3, 4]`.

Объяснение: `dict.copy()` - это поверхностное копирование. Копируется только сам словарь верхнего уровня, а вложенный список `items` остаётся общим объектом для `a` и `b` (алиасинг), поэтому изменение через `b` видно и в `a`.

## Задание 7. `Counter` - быстрый ответ

```python
[('a', 3), ('b', 2)]
```

`Counter` считает количество вхождений каждого элемента (`"a"` встречается 3 раза, `"b"` - 2, `"c"` - 1), а `.most_common(2)` возвращает 2 самых частых элемента в порядке убывания частоты.

## Задание 8. `defaultdict` vs обычный `dict`

```python
from collections import defaultdict

counts = defaultdict(int)
for word in ["кот", "пёс", "кот"]:
    counts[word] += 1
```

`defaultdict(int)` автоматически создаёт запись со значением `0` при первом обращении к отсутствующему ключу, поэтому явная проверка `if key not in counts` больше не нужна.

## Задание 10. Рекурсия - базовый случай

```python
def sum_to_n(n):
    if n <= 0:
        return 0

    return n + sum_to_n(n - 1)
```

Если базовый случай не написать, рекурсия не остановится: функция будет вызывать саму себя бесконечно (с уменьшающимся `n`, уходящим в отрицательные значения), что приведёт к переполнению стека вызовов - `RecursionError: maximum recursion depth exceeded`.

### На подумать

**Задание:** На основе «грязного» JSON-файла с заказами (предоставляется преподавателем):
1. Разобрать с помощью `json.load`.
2. Использовать `Counter` для нахождения топ-5 категорий по количеству заказов.
3. Использовать `defaultdict` для подсчёта суммарной выручки по категориям.
4. Корректно обрабатывать отсутствующие поля (`.get()` со значениями по умолчанию).
5. Вывести результаты в виде чистого JSON-файла.


**Тест**

1. Какова сложность операции `x in my_set` vs `x in my_list` для больших коллекций?
   > `my_set`: O(1). `my_list`: O(n). При 1 млн элементов множество работает примерно в 200 раз быстрее.

2. Что выведет этот код и почему?
   ```python
   a = [1, 2]
   b = a
   b.append(3)
   print(a)
   ```
   > `[1, 2, 3]` — `b` является псевдонимом `a`, а не копией. Они ссылаются на один и тот же объект списка.

3. Перепишите с помощью `defaultdict`:
   ```python
   d = {}
   for k, v in data:
       if k not in d:
           d[k] = []
       d[k].append(v)
   ```
   > `from collections import defaultdict; d = defaultdict(list); [d[k].append(v) for k, v in data]`

4. Почему нельзя использовать `list` в качестве ключа словаря?
   > Списки изменяемы и поэтому не являются хешируемыми. Ключи словаря должны быть хешируемыми.

5. Каков результат `Counter("banana") - Counter("nan")`?
   > `Counter({'b': 1, 'a': 2})` — вычитание сохраняет только положительные счётчики. `n: 2-2=0`, `a: 3-1=2`.

## Домашнее задание 3 — Структуры данных Python

1. Дан список словарей-транзакций (`{"id":..., "amount":..., "category":...}`). Напишите функцию, которая возвращает топ-N категорий по суммарной сумме, используя только встроенные структуры и `collections`.
2. Объясните (короткий письменный ответ), почему `a = [[0]*3]*3` — частая ошибка, и как её исправить. Свяжите это с обсуждением изменяемости.
3. Дан вложенный JSON (список заказов, каждый заказ содержит список товаров с ценой и количеством). Напишите функцию, которая возвращает "плоский" список словарей (один словарь на товар, с добавленным id заказа), без использования pandas.
4. Реализуйте простой LRU-кэш (least recently used) на основе `dict` и `collections.deque` (или `OrderedDict`) без использования `functools.lru_cache` — с методами `get(key)` и `put(key, value)` и ограничением размера. Объясните, какие операции должны быть O(1) и почему.
5. Даны два больших списка идентификаторов пользователей (списки могут содержать дубликаты). С помощью множеств (`set`) реализуйте функции для пересечения, разности и объединения списков и сравните по сложности с наивной реализацией через вложенные циклы (`O(n*m)` vs `O(n+m)`).

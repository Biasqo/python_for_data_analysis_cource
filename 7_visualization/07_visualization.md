# Глава 7 - Визуализация данных: Matplotlib, Seaborn и Streamlit

Визуализация данных нужна не только для оформления отчётов. Графики позволяют обнаружить закономерности, выбросы и различия между группами, которые не видны в сводных статистиках. В этой главе рассмотрим построение графиков в `matplotlib`, статистическую визуализацию в `seaborn` и создание интерактивных приложений на `Streamlit`.

Для примеров используются `numpy`, `pandas`, наборы данных `anscombe`, `penguins`, `tips`, `flights` и синтетические данные. Предполагается знакомство с основами Python и `pandas`.

## Часть 1. Зачем нужна визуализация

### 1.1 Визуализация как инструмент анализа

**Основная идея:** визуализация — инструмент *анализа*, а не оформления.

**Квартет Анскомба** показывает, почему одинаковые статистические показатели не означают одинаковую структуру данных. У четырёх наборов почти совпадают среднее значение, стандартное отклонение и корреляция, но графики показывают линейную зависимость, нелинейную зависимость, влияние выброса и скопление точек.

```text
Одинаковые сводные статистики
             │
      ┌──────┼──────┬────────┐
      ▼      ▼      ▼        ▼
   Линия  Кривая  Выброс  Кластер
      └──────┴──────┴────────┘
             │
     Разные выводы
```

Различают исследовательскую визуализацию (поиск закономерностей), объяснительную (передача вывода) и интерактивную (изучение данных через фильтры и элементы управления).

## Часть 2. Matplotlib

### 2.1 Объектная модель Figure и Axes

**Основной принцип:** используем **объектно-ориентированный API**: `fig, ax = plt.subplots()`. Неявный `plt.plot` допустим только для одноразовых набросков.

### 2.2 Основные графики и настройка

| Инструмент | Назначение |
|---|---|
| `ax.plot` | Линейные графики и временные ряды |
| `ax.scatter` | Связь числовых признаков; цвет и размер могут кодировать дополнительные переменные |
| `ax.bar`, `ax.barh` | Сравнение категорий |
| `ax.hist` | Распределение числовой переменной |
| `ax.annotate`, `ax.axvspan` | Подписи и выделение важных областей |
| `plt.subplots`, `plt.subplot_mosaic` | Несколько панелей на одной фигуре |
| `fig.savefig` | Сохранение в PNG, SVG или PDF |

В `matplotlib` объект `Figure` представляет всю фигуру, а `Axes` — отдельную область построения. Объект `Axis` управляет шкалой и делениями оси. Для сложных компоновок удобно использовать `constrained_layout=True`. Двойная ось `twinx()` и логарифмическая шкала полезны только при осмысленном выборе масштаба: они могут затруднить сравнение.

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4), constrained_layout=True)
ax.plot([1, 2, 3, 4], [2, 5, 4, 7], marker="o", label="Наблюдения")
ax.set(title="Динамика показателя", xlabel="Период", ylabel="Значение")
ax.legend()
fig.savefig("chart.png", dpi=200)
plt.show()
```

**Типичные ошибки:**

- Смешивают `plt.title(...)` и `ax.set_title(...)` в одной ячейке → подписи попадают «не туда». Правило: *в OO-стиле только методы `ax`*.
- Забывают `plt.show()` вне Jupyter / не закрывают фигуры (`plt.close(fig)`) в циклах → «too many open figures».
- `savefig` **после** `plt.show()` сохраняет пустую картинку (в некоторых бэкендах). Сначала `savefig`, потом `show`.
- Путают `ax.set_xlabel` и `ax.xlabel` (атрибута нет). Удобно: `ax.set(title=..., xlabel=..., ylabel=...)`.
- В `bar` передают `pandas.Series` с категориальным индексом и получают числовые метки — приводить `index.astype(str)`.

## Часть 3. Seaborn

### 3.1 Статистическая визуализация и tidy-данные

**Основной принцип:** seaborn = *статистика + tidy-данные + matplotlib под капотом*. Две «этажности»: **axes-level** (рисует в `ax=`) и **figure-level** (создаёт фигуру, умеет `col=`/`row=`).

### 3.2 Распределения, категории и связи

Для анализа распределений подходят `histplot`, `kdeplot` и `ecdfplot`. Число интервалов гистограммы влияет на восприятие формы распределения; `ECDF` не требует выбора параметра сглаживания. При сравнении групп полезно сочетать `boxplot` со `stripplot`, чтобы не скрывать отдельные наблюдения.

Для категорий используйте `countplot`, когда нужно посчитать наблюдения, и `barplot`, когда требуется оценить агрегированную величину. Для связи числовых признаков подходят `scatterplot`, `lineplot` и `regplot`. Для матриц корреляций применяйте `heatmap` с расходящейся палитрой и `center=0`; для быстрого разведочного анализа нескольких признаков — `pairplot`.

### 3.3 Axes-level и figure-level

Axes-level функции, например `sns.scatterplot`, рисуют на переданном объекте `ax`. Figure-level функции, например `sns.relplot` или `sns.displot`, создают собственную фигуру и позволяют строить панели с помощью `col=` и `row=`.

```python
import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("penguins")
fig, ax = plt.subplots()
sns.scatterplot(data=df, x="bill_length_mm", y="bill_depth_mm", hue="species", ax=ax)
plt.show()

g = sns.relplot(data=df, x="bill_length_mm", y="bill_depth_mm", col="species")
g.figure.suptitle("Пингвины по видам", y=1.05)
```

**Таблица выбора функции seaborn:**

| Вопрос к данным | Одна переменная | Две переменные | Три+ переменных |
|---|---|---|---|
| Как распределено? | `histplot`, `kdeplot`, `ecdfplot` | `kdeplot(x,y)`, `jointplot` | `pairplot`, `displot(col=)` |
| Как отличаются группы? | `countplot` | `boxplot`, `violinplot`, `barplot`, `stripplot` | `catplot(hue=, col=)` |
| Как связаны? | — | `scatterplot`, `regplot`, `lineplot` | `relplot(hue=, size=, col=)`, `lmplot` |
| Матрица значений | — | — | `heatmap`, `clustermap` |

**Демонстрация «ага-эффекта»:** парадокс Симпсона на `penguins`. Слева — общая регрессия с отрицательным наклоном, справа — внутри каждого вида наклон положительный. Причина такого различия — скрытая группирующая переменная: вид пингвина. У разных видов различается форма клюва.

**Типичные ошибки:**

- Передают в seaborn «широкий» DataFrame и не понимают, почему `hue` не работает → `melt`.
- Пытаются положить figure-level функцию в `ax=` → `TypeError`/`UserWarning`; правильно — `g.axes`, `g.figure`, или перейти на axes-level.
- `plt.title()` после `displot` подписывает только последнюю панель → использовать `g.set_titles()`, `g.figure.suptitle()`.
- `sns.barplot` воспринимают как «частоты» — на деле это **среднее** (по умолчанию) с ДИ; для частот — `countplot`.
- Пропуски в данных молча отбрасываются — проверить `df.isna().sum()` до построения.
- Увеличение размера figure-level графика через `plt.figure(figsize=...)` не работает — нужны `height=` и `aspect=`.

## Часть 4. Принципы хорошей визуализации

### 4.1 Выбор графика и визуальных кодировок

**Основной принцип:** хороший график отвечает на конкретный вопрос и заканчивается выводом. Цель — *понимание*, а не «красота».

**Выбор типа графика:**

| Задача | Хороший выбор | Избегать |
|---|---|---|
| Распределение | гистограмма, KDE, ECDF, box/violin | pie |
| Сравнение категорий | столбцы (отсортированные), dot plot | 3D-столбцы, pie при > 3 долях |
| Динамика во времени | линия | столбцы для плотных рядов |
| Связь двух числовых | scatter (+ тренд), hexbin при большом n | соединять несвязанные точки линией |
| Части целого | stacked bar, treemap | pie с 7+ секторами |
| Много переменных | small multiples (`col=`), `pairplot`, heatmap | 6 кодировок на одном графике |

**Практикум «почините график» — ответы:**

| Проблема на «плохом» графике | Исправление |
|---|---|
| нет заголовка, подписей осей, единиц | вывод в заголовке; `ylabel="Средние чаевые, $"` |
| метки оси X — числа 0…3 | подписать днями недели |
| обрезанная ось Y (2.5–3.3) раздувает разницу | столбцы — ось от нуля |
| `jet`-раскраска без смысла | серый + один акцентный цвет |
| тяжёлая сетка | убрать или сделать светлой; `sns.despine()` |
| нет неопределённости | ДИ (`yerr=1.96*sem`) |
| нет вывода | формулировка в заголовке |

**Обсуждение:** на «хорошем» графике доверительные интервалы дней перекрываются — поэтому заголовок осторожнее, чем «воскресенье — лучший день». Различие «выше в выборке» и «статистически значимо выше» — повод напомнить о проверке гипотез.

## Часть 5. Streamlit

### 5.1 Модель выполнения приложения

**Основной принцип:** *каждое действие пользователя перезапускает весь скрипт сверху вниз.* Из этого вытекают кэш, `session_state` и стиль написания кода.

### 5.2 Состояние приложения

При изменении слайдера или нажатии кнопки Streamlit заново выполняет скрипт. Обычная локальная переменная при этом пересоздаётся, а `st.session_state` сохраняет данные в рамках пользовательской сессии.

```text
Пользователь меняет фильтр
            │
            ▼
   Повторный запуск скрипта
            │
      ┌─────┴─────┐
      ▼           ▼
  Кэш данных   Состояние сессии
  cache_data   session_state
      │           │
      └─────┬─────┘
            ▼
    Обновлённый дашборд
```

### 5.3 Устройство интерактивного дашборда

Дашборд объединяет загрузку данных, фильтрацию, сводные показатели и несколько визуальных представлений. `st.sidebar` размещает элементы управления; `st.multiselect` выбирает категории; `st.columns` и `st.tabs` организуют экран. `st.metric` показывает агрегированные значения, а `st.pyplot` отображает фигуры matplotlib.

`@st.cache_data` кэширует результаты вычислений и чтения данных, чтобы повторные запуски не выполняли одну и ту же работу. `st.session_state` хранит пользовательское состояние между запусками. `st.stop()` прекращает выполнение, например, когда после фильтрации не осталось наблюдений.

```text
       Исходные данные
              │
              ▼
       Загрузка и кэш
              │
              ▼
      Фильтры пользователя
              │
      ┌───────┴────────┐
      ▼                ▼
  Сводные метрики   Графики
      │                │
      └───────┬────────┘
              ▼
       Экспорт данных
```

**Ограничения:** тяжёлые вычисления без кэша замедляют приложение; глобальные переменные не заменяют состояние сессии; фигуры matplotlib при многократной перерисовке следует закрывать для экономии памяти.

## Домашнее задание 1 — Python: синтаксис и экосистема

1. Напишите скрипт, который читает CSV-файл (модуль `csv`), вычисляет для числового столбца минимум, максимум, среднее и количество пропущенных значений, и выводит результат в виде словаря.
2. Объясните письменно (3–5 предложений), почему `def f(x=[]): x.append(1); return x` — частая ошибка, и предложите исправление.
3. Используя `pathlib`, напишите функцию, которая рекурсивно находит все файлы с расширением `.csv` в заданной директории и возвращает их пути, отсортированные по размеру файла (по убыванию).
4. Напишите скрипт, принимающий путь к файлу через `sys.argv`, который выводит количество строк, количество столбцов и список названий столбцов CSV-файла. Добавьте понятное сообщение об ошибке, если файл не найден или путь не передан.
5. Короткий письменный ответ: объясните разницу между `==` и `is` при сравнении с `None`. Почему `if x == None` считается плохим стилем, и в каком (редком) случае разница между `==` и `is` для `None` действительно может проявиться?

## 3. Работа с `None` и условными выражениями

Дан код:

```python
def get_name(name=None):
    if not name:
        return "Anonymous"
    return name
```

### Часть 1

Не запуская код, определите результат:

```python
print(get_name())
print(get_name(""))
print(get_name("Alice"))
print(get_name(0))
```

1. Почему `""` и `0` приводят к одному и тому же результату?
2. Какие значения в Python считаются ложными (*falsy*)?

### Часть 3

Измените функцию так, чтобы значение `"Anonymous"` возвращалось **только** в случае, когда аргумент равен `None`.

Например:

```python

```

## 5. Мини-отчёт в JSON

```python

    "student": "Ваше имя",

    "score": ?,

}
```

* `completed_tasks` вводится пользователем;
* `score` вычисляется как `completed_tasks * 20`;
* `passed` равно `True`, если `score >= 60`.

После этого:

1. сохраните словарь в файл `summary.json`;
2. прочитайте файл обратно;
3. выведите значение `score` и `passed`.

```python
True
```

Список содержит один элемент, поэтому он является истинным (*truthy*), независимо от значения этого элемента.

## 2. Какая ошибка есть в этом коде?

```python
def append_item(val, lst=[]):
    lst.append(val)
    return lst
```

Используется изменяемый аргумент по умолчанию (*mutable default argument*).

Список создаётся один раз при определении функции и затем переиспользуется:

```python
append_item(1)  # [1]
append_item(2)  # [1, 2]
append_item(3)  # [1, 2, 3]
```

Правильный вариант:

```python
def append_item(val, lst=None):
    if lst is None:
        lst = []
    lst.append(val)
    return lst
```

## 3. Что выведет этот код?

```python
a = [1, 2, 3]
b = a
b.append(4)

print(a)
```

Результат:

```python
[1, 2, 3, 4]
```

`a` и `b` ссылаются на один и тот же объект в памяти.

## 4. Что выведет этот код?

```python
x = "hello"

def f(print_result: str):
    print(print_result)

f(x)
```

Результат:

```python
hello
```

Аннотация типа `: str` никак не влияет на выполнение программы. Она используется только для документации и инструментов проверки типов.

## 5. Что выведет этот код?

```python
print(7 // 2)
print(7 / 2)
```
Результат:

```python
3
3.5
```

Разница:

* `/` выполняет обычное деление и всегда возвращает `float`.
* `//` выполняет целочисленное деление (floor division).

Примеры:

```python
7 // 2    # 3
7 / 2     # 3.5
8 // 4    # 2
```

Интересный случай:

```python
-7 // 2   # -4
```

`//` округляет вниз (*towards negative infinity*).

## 6. Что выведет этот код?

```python
print(7 % 2)
print(10 % 3)
print(8 % 4)
```

Результат:

```python
1
1
0
```

Оператор `%` возвращает остаток от деления.

Примеры:

```python
7 % 2   # 1
10 % 3  # 1
8 % 4   # 0
```

Часто используется для проверки чётности:

```python
n % 2 == 0
```

## 7. Что выведет этот код?

```python
a = [1, 2]
b = [1, 2]

print(a == b)
print(a is b)
```

Результат:

```python
True
False
```

Разница:

* `==` сравнивает значения объектов.
* `is` проверяет, являются ли объекты одним и тем же объектом в памяти.

```python
c = a

c == a  # True
c is a  # True
```

## 8. Что выведет этот код?

```python
print(5 == 5.0)
print(type(5))
print(type(5.0))
```

Результат:

```python
True
<class 'int'>
<class 'float'>
```

Python считает числа `5` и `5.0` равными по значению, несмотря на разные типы.

## 9. Что выведет этот код?

```python
x = 256
y = 256

print(x is y)
```

Обычно:

```python
True
```

Python кэширует небольшие целые числа (обычно от `-5` до `256`).

Однако полагаться на это поведение нельзя:

```python
x = 1000
y = 1000

print(x is y)
```

Результат зависит от реализации Python и способа создания объектов.

Используйте:

```python
x == y
```

для сравнения чисел.

## 10. Что выведет этот код?

```python
print(bool(""))
print(bool(" "))
print(bool(0))
print(bool(1))
```

Результат:

```python
False
True
False
True
```

Ложными (*falsy*) значениями являются:

```python
False
None
0
0.0
0j
''
[]
{}
set()
()
range(0)
```

Практически всё остальное считается истинным (*truthy*), включая:

```python
" "
[0]
[False]
"0"
```

Пустая строка ложная, а строка из одного пробела истинная. Компьютеры иногда напоминают джиннов: исполняют желание буквально и потом смотрят, как человек удивляется.

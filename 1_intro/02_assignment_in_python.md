# Что происходит при `x = 5` и `a = x`

## Шаг 1: `x = 5`

```python
x = 5
```

### Что происходит в памяти

1. Создаётся объект `5` (тип `int`) в памяти.
2. Переменная `x` начинает ссылаться на этот объект.

```text
Память:

┌─────────────┐
│  объект 5   │  ← адрес: 0x1234
└─────────────┘
      ▲
      │
    ┌─┴─┐
    │ x │  (ссылка на 0x1234)
    └───┘
```

---

## Шаг 2: `a = x`

```python
a = x
```

### Что происходит в памяти

1. Python смотрит на объект, на который указывает `x`.
2. Это объект `5` с адресом `0x1234`.
3. Переменная `a` начинает ссылаться на тот же самый объект.

```text
Память:

┌─────────────┐
│  объект 5   │  ← адрес: 0x1234
└─────────────┘
      ▲
      │
    ┌─┴─┐
    │ x │  (ссылка на 0x1234)
    └───┘
      ▲
      │
    ┌─┴─┐
    │ a │  (ссылка на 0x1234)
    └───┘
```

---

## Ключевой момент

**Копия объекта `5` не создаётся.**

Существует только:

* один объект `5`;
* две переменные (`x` и `a`), которые ссылаются на него.

---

## Что произойдёт, если изменить `x`?

```python
x = 5
a = x

x = 10

print(x)  # 10
print(a)  # 5
```

### Почему так происходит?

После выполнения:

```python
x = 10
```

переменная `x` начинает ссылаться на **новый объект** `10`.

Переменная `a` продолжает ссылаться на старый объект `5`.

---

## Состояние памяти после `x = 10`

```text
┌─────────────┐
│  объект 5   │  ← адрес: 0x1234
└─────────────┘
      ▲
      │
    ┌─┴─┐
    │ a │
    └───┘


┌─────────────┐
│ объект 10   │  ← адрес: 0x5678
└─────────────┘
      ▲
      │
    ┌─┴─┐
    │ x │
    └───┘
```

---

## Итог

Присваивание в Python не копирует объект.

Операция:

```python
a = x
```

означает:

> «Пусть `a` ссылается на тот же объект, что и `x`».

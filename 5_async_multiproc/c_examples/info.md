Функция sum_of_squares_parallel вычисляет сумму квадратов всех элементов массива параллельно с помощью OpenMP. Сначала она создаёт отдельную параллельную область (#pragma omp parallel), внутри которой директива #pragma omp single поручает ровно одному потоку запомнить фактическое число потоков через omp_get_num_threads(), а затем это значение выводится на экран.

После этого начинается основная работа: #pragma omp parallel for reduction(+ : total) schedule(static) разбивает цикл по индексам массива на равные непрерывные куски — по одному на каждый поток. Каждый поток независимо проходит свой диапазон, возводит элементы в квадрат и накапливает их в собственной приватной копии переменной total. Директива reduction(+ : total) гарантирует, что в конце все приватные суммы будут корректно сложены в одну общую без гонок данных и без ручных блокировок.

## Задание 5. Отладка гонки данных (race condition) в multiprocessing
Ниже — код, который должен посчитать сумму от 4 процессов в общую переменную, но результат каждый раз разный и неверный:

```python
from multiprocessing import Process, Value

def worker(counter, n):
    for _ in range(n):
        counter.value += 1

if __name__ == "__main__":
    counter = Value("i", 0)
    processes = [Process(target=worker, args=(counter, 100_000)) for _ in range(4)]
    for p in processes:
        p.start()
    for p in processes:
        p.join()
    print(counter.value)  # ожидается 400000, но получается меньше
```

1. Объясните, почему результат не равен 400 000 (в чём природа гонки данных здесь, ведь `Value` — это разделяемая память, а не полностью изолированный объект, как обычно бывает при multiprocessing).
2. Исправьте код с помощью `multiprocessing.Lock`, чтобы результат был детерминирован.
3. Оцените, насколько добавление `Lock` замедлило выполнение по сравнению с (некорректной) версией без блокировки, и объясните, почему.

def process_chunk(args):
    arr, start, end = args
    return arr[start:end].sum()

    chunks = [(data, i * 25_000_000, (i + 1) * 25_000_000) for i in range(4)]

    async with session.get(url) as resp:

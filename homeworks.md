# Блок 1

## Занятие 1. Python: синтаксис и экосистема

**Домашнее задание 1:**
1. Напишите скрипт, который читает CSV-файл (модуль `csv`), вычисляет для числового столбца минимум, максимум, среднее и количество пропущенных значений, и выводит результат в виде словаря.
2. Объясните письменно (3–5 предложений), почему `def f(x=[]): x.append(1); return x` — частая ошибка, и предложите исправление.
3. Используя `pathlib`, напишите функцию, которая рекурсивно находит все файлы с расширением `.csv` в заданной директории и возвращает их пути, отсортированные по размеру файла (по убыванию).

## Занятие 2. Продвинутый Python: синтаксический сахар, типизация, парадигмы программирования

**Домашнее задание 2:**
1. Перепишите предоставленный "плохой" скрипт в идиоматичный Python: используйте comprehensions/генераторы там, где это уместно, добавьте type hints ко всем функциям и обработку исключений для некорректных строк входных данных.
2. Опишите с помощью `@dataclass` структуру "Транзакция" (id, дата, сумма, категория) и напишите функцию `total_by_category(transactions: list[Transaction]) -> dict[str, float]`.
3. Реализуйте контекстный менеджер (классом **и** через `contextlib.contextmanager`), который замеряет время выполнения блока кода и печатает результат.
